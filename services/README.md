# Backend Microservices

This directory contains the independently deployable backend services of the Smart Fleet & Logistics Management System.

## Services

- `auth-user-service` – authentication, authorization, and user management
- `fleet-vehicle-service` – vehicle and fleet management
- `dispatch-trip-service` – dispatch and trip management
- `tracking-telemetry-service` – vehicle tracking and telemetry processing
- `reporting-service` – operational reporting and data analysis
